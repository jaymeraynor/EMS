❓ 常見問題

如何升級版本？ +
您可以隨時升級到更高版本。我們會按比例退款現有訂閱，新版本費用立即生效。升級過程無縫進行，無需重新配置。
Advance 版本的限制是什麼？ +
Advance 版本限制於單個電表、3 種基本協議、無歷史數據分析和無 API 支持。適合個人和小型企業測試使用。
Pro 版本支持哪些協議？ +
Pro 版本支持 10+ 種主流協議：Modbus RTU/TCP、MQTT、HTTP REST、IEC 60870、DNP3、OPC UA、DLT645、CJ/T188 等。
Ultimate 版本可以支持無限電表嗎？ +
是的，Ultimate 版本支持無限數量的電表，同時支持所有協議和高級功能。完全滿足企業級需求。
可以同時使用真實和虛擬電表嗎？ +
Pro 和 Ultimate 版本支持混合使用。您可以配置若干真實電表和虛擬電表，隨時切換使用。
如何獲得技術支持？ +
Advance 版本享受社區支持，Pro 版本提供郵件支持（48 小時內回復），Ultimate 版本享受 24/7 專業支持。
