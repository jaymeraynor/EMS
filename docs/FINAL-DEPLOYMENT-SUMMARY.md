## 🚀 快速部署流程（5 步，15 分鐘）

### 第 1 步：準備（5 分鐘）
```bash
# 1. 確認環境
docker --version    # ✅ Docker 已安裝
docker-compose --version  # ✅ Docker Compose 已安裝
free -h             # ✅ 至少 2GB RAM 可用

# 2. 下載並進入目錄
cd /opt/elitegets/

# 3. 查看部署指南
cat QUICK-START-DEPLOYMENT.md
```

### 第 2 步：配置（3 分鐘）
```bash
# 1. 複製環境變量
cp .env.example .env

# 2. 編輯關鍵密碼（至少改變這些！）
nano .env
# 修改：
#   DB_PASSWORD: 設置強密碼
#   JWT_SECRET: 生成 32+ 字符密鑰
#   GRAFANA_PASSWORD: 設置密碼
```

### 第 3 步：構建（2 分鐘）
```bash
# 構建 Docker 鏡像
docker-compose build
```

### 第 4 步：啟動（2 分鐘）
```bash
# 啟動所有容器
docker-compose up -d

# 等待 30 秒
sleep 30

# 查看狀態
docker-compose ps  # 所有應該顯示 Up
```

### 第 5 步：驗證（3 分鐘）
```bash
# 前端
curl http://localhost/
# 應返回 HTML

# 後端
curl http://localhost:8000/health
# 應返回 {"status":"ok"}

# 檢查所有服務
curl http://localhost:3000      # Grafana
curl http://localhost:9090      # Prometheus
curl http://localhost:8086      # InfluxDB
```

## 🆘 常見問題 Q&A

**Q: 部署失敗怎麼辦？**
A: 查看 QUICK-START-DEPLOYMENT.md 的故障排查部分

**Q: 如何停止或重啟服務？**
A: 
```bash
docker-compose stop      # 停止
docker-compose start     # 啟動
docker-compose restart   # 重啟
docker-compose logs -f   # 查看日誌
```

**Q: 如何備份數據？**
A: PostgreSQL 和 Redis 數據已通過 Docker volume 持久化

**Q: 生產環境如何配置 HTTPS？**
A: 配置 Nginx 和 SSL 證書（使用 Let's Encrypt）

**Q: 如何擴展系統？**
A: 使用 Docker Compose 的 `scale` 命令或 Kubernetes
